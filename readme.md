## Pythonの学習用
このリポジトリは、Python公式ドキュメントを読んで、
実際に動作確認したコードをまとめたものとなっています。

## 構成
### standard-library
Pythonの標準ライブラリの使い方を学ぶためのコードを収録しています。

## control-flow
制御文のコードをまとめています。
match case,for elseなど。

## function-annotation
型アノテーションを動かしたコードとなっています。
typingなども。

## read & write
データのread writeについて。
